# Classificação com Claude

Aprenda como usar o Claude para tarefas de classificação, especialmente em cenários com regras de negócio complexas e dados de treinamento limitados.

## Conteúdo

- `guide.ipynb`: Notebook do tutorial principal
- `data/`: Arquivos de dados para exemplos e testes
- `evaluation/`: Scripts de avaliação usando Promptfoo

Para instruções de avaliação, veja `evaluation/README.md`.
