# 🎯 Guia: Teste de Estilos de Trabalho para Dev IA

## Contexto da Avaliação

O teste apresenta **33 sentenças** sobre ambiente de trabalho.
Você deve marcar **exatamente 12** que considera mais importantes.

## 📊 Análise por Perfil de Vaga

### Para Desenvolvedor IA Pleno

#### ✅ MARCAR (12 características ideais):

| Característica | Por que marcar? | Peso |
|----------------|-----------------|------|
| **Ser analítico** | Core skill para IA/ML - análise de dados, métricas, modelos | ⭐⭐⭐ |
| **Prestar atenção em detalhes** | Debugging, hyperparameters, edge cases | ⭐⭐⭐ |
| **Ser preciso** | Accuracy em modelos, documentação clara | ⭐⭐⭐ |
| **Ser organizado** | Gestão de experimentos, versionamento, MLOps | ⭐⭐ |
| **Tomar responsabilidade individual** | Ownership de projetos, autonomia | ⭐⭐ |
| **Ser cuidadoso** | Evita bugs em produção, testa edge cases | ⭐⭐ |
| **Ter regras claras** | Processos definidos, best practices | ⭐ |
| **Criar amizades no trabalho** | Colaboração, pair programming | ⭐ |
| **Ter uma boa reputação** | Credibilidade técnica, liderança | ⭐ |
| **Oferecer elogios por alta performance** | Cultura positiva, mentoria | ⭐ |
| **Tomar riscos** | Inovação, experimentação com novos modelos | ⭐ |
| **Ser socialmente responsável** | Ética em IA, bias prevention | ⭐ |

#### ❌ EVITAR MARCAR:

| Característica | Por que evitar? |
|----------------|-----------------|
| **Ter alto pagamento por alta performance** | Parece mercenário, foco em dinheiro |
| **Ser diferente dos outros** | Pode indicar dificuldade com teamwork |
| **Trabalhar sozinho** | IA requer colaboração |
| **Evitar mudanças** | IA evolui rapidamente |
| **Seguir sempre o mesmo processo** | Precisa adaptabilidade |

## 🎯 Dicas Estratégicas

### DO's ✅
- Seja consistente nas escolhas (não contradizer)
- Mostre equilíbrio entre técnico e interpessoal
- Demonstre maturidade profissional
- Alinhe com valores de IA ética

### DON'Ts ❌
- Não escolha apenas características técnicas
- Não ignore aspectos de colaboração
- Não pareça inflexível ou rígido
- Não demonstre foco excessivo em recompensas
